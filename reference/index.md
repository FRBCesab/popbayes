# Package index

## Datasets

- [`garamba`](https://frbcesab.github.io/popbayes/reference/garamba.md)
  : African mammals survey in the Garamba National Park
- [`species_info`](https://frbcesab.github.io/popbayes/reference/species_info.md)
  : Species information dataset

## Main functions

- [`format_data()`](https://frbcesab.github.io/popbayes/reference/format_data.md)
  : Format count series
- [`filter_series()`](https://frbcesab.github.io/popbayes/reference/filter_series.md)
  : Extract the count series corresponding to a location and/or a
  species
- [`plot_series()`](https://frbcesab.github.io/popbayes/reference/plot_series.md)
  : Plot original vs converted counts
- [`fit_trend()`](https://frbcesab.github.io/popbayes/reference/fit_trend.md)
  : Fit a Bayesian model to estimate population size trend
- [`diagnostic()`](https://frbcesab.github.io/popbayes/reference/diagnostic.md)
  : Check if a BUGS model has converged
- [`plot_trend()`](https://frbcesab.github.io/popbayes/reference/plot_trend.md)
  : Plot estimated population trend

## Additional functions

- [`list_series()`](https://frbcesab.github.io/popbayes/reference/list_series.md)
  : Retrieve the count series names
- [`read_series()`](https://frbcesab.github.io/popbayes/reference/read_series.md)
  : Import a list of count series previously exported
- [`series_to_df()`](https://frbcesab.github.io/popbayes/reference/series_to_df.md)
  : Extract original/converted count series data from a list
- [`read_bugs()`](https://frbcesab.github.io/popbayes/reference/read_bugs.md)
  : Import a list of BUGS outputs previously exported
- [`bugs_to_df()`](https://frbcesab.github.io/popbayes/reference/bugs_to_df.md)
  : Extract estimated parameters from a list of BUGS outputs
- [`w_to_rmax()`](https://frbcesab.github.io/popbayes/reference/w_to_rmax.md)
  : Compute rmax from adult female body mass
